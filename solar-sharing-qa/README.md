# 営農型太陽光発電の制度改正 パブリックコメント結果Q&A

農林水産省の2026年10月9日公示資料を検索できる非公式ポータルです。3案件157項目の意見・回答を収録しています。

## ファイル
- `index.html`：ページ本体、3案件の結果一覧、出典・編集方針
- `style.css`：レスポンシブな表示
- `app.js`：検索、論点・案件絞り込み、保存、個別リンク
- `data.json`：意見と回答、資料のページ、公式出典URL

## 団体サイトへの移行
4ファイルを同じ公開フォルダへ配置してください。ビルド、データベース、APIキーは不要です。ルートにもサブディレクトリにも設置できます。既存ファイルを上書きしない専用フォルダを推奨します。

GitHub Pagesの場合はリポジトリの Settings → Pages で対象ブランチのルートを公開元に設定します。Pages設定はこのリポジトリの作成だけでは有効になりません。

ローカル確認は `python -m http.server 8000` を実行して `http://localhost:8000` を開きます。HTMLファイルをダブルクリックする方法ではJSONの読み込みが制限される場合があります。

公開後は検索、案件絞り込み、保存、個別Q&Aリンク、PDFリンクを確認してください。旧サイトの個別リンクは自動転送されません。移行先ドメインではブラウザ内の保存項目は引き継がれません。

## 更新
本文データは `data.json`、編集要約は `app.js` の `points`、一覧表と収録日は `index.html` を更新します。項目IDを維持すると個別リンクが継続して利用できます。公式回答と編集要約を区別し、出典を残してください。制度の自動更新機能はありません。
